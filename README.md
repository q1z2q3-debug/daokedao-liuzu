# 润泽说 道可道之六祖坛经 · 自性五句与风幡公案（存疑稿）

> **此篇经作者判定不成立。** 故标"存疑稿"，不并入任何正式读本的附录，也不能当作定论引用。文字保留原貌，留作对照与待改之据。

## 这是什么

对《坛经·行由品》两处的一次解读尝试：

1. 六祖闻《金刚经》「应无所住而生其心」言下大悟，说出那五句「何期自性」；
2. 「不是风动，不是幡动，仁者心动」这则公案。

尝试的做法，是用「三才五蕴太极空杯」把两处逐层对看，看能不能并到一个框架里讲通。

尝试的结果是：**讲不通。** 作者判定不成立。

## 为什么要单独建一个库

因为这批文字原来在别处。

- 2026-11-14，此篇拟作《[润泽说 道可道之金刚经](https://github.com/q1z2q3-debug/daokedao-jingang)》读本的**附录六**，随 v1.0.1 上架。
- 同日，作者指出解读不成立。
- 该读本 v1.0.2 将附录六撤下，书稿恢复为附录一至五。

撤下之后，文字不当销毁，也不宜混在成书里。所以移存本库，单独挂一个"存疑稿"的名，附一份说明。

**判断错在哪，比一句"错了"更有用——前提是它被标明是错的。**

## 怎么用这一篇

- 可以读，可以引，**但须一并引"说明"**；只引正文不引说明，等于把一次失败的尝试当成结论。
- 篇中"五句 ↔ 空杯五剖面""风幡 ↔ 杯不动水动"等推演，不可当作《坛经》的义解引用。
- 凡本稿与正式读本冲突处，一律以正式读本为准。
