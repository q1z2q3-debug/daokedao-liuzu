# 润泽说 道可道之六祖坛经 · 自性五句与风幡公案（重校本）

> **重校本 v0.2.0。** 此前两版解读经作者指出不成立，已整篇替换（旧稿仅存 git 历史）；本版依《心经通释》原版「三才五蕴太极空杯」重写，以**幡为阴、风为阳、慧能之心为太和**立骨，会通《金刚经》「应无所住而生其心」「此心非心，故名此心」。

## 这是什么

对《坛经·行由品》两处的一次解读尝试：

1. 六祖闻《金刚经》「应无所住而生其心」言下大悟，说出那五句「何期自性」；
2. 「不是风动，不是幡动，仁者心动」这则公案。

做法是以「三才五蕴太极空杯」把两处并到一处讲：五句明体，风幡显用，体用同证。

落点四柱：**体**（五句所证，是不被五蕴器框拘限的空性本际）／**用**（风幡落在缘起里，如实显现）／**阴阳**（幡阴风阳，二僧各执一边）／**心**（涵摄阴阳的太和，是指代词——此心非心，故名此心）。

## 怎么用这一篇

- 模型部分以《心经通释》原版为准；若与《心经》书稿用语不合，依《心经》书稿。
