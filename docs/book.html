说明

一、这一篇是什么

《坛经·行由品》两段，一体通释：

其一，六祖闻五祖说《金刚经》至「应无所住而生其心」，言下大悟，说出「何期自性」五句。
其二，广州法性寺，风吹幡动，二僧一曰风动、一曰幡动，议论不已；慧能曰「不是风动，不是幡动，仁者心动」。

本篇以「三才五蕴太极空杯」为镜，把两段并到一处讲：五句明体，风幡显用，体用同证，落在一句「应无所住而生其心」上。

二、两版作废，三条勘误

此篇先有两版，经作者指出解读不成立，均作废，仅存于 git 历史。错在三处，记在此处，以免日后再犯：

误一：三才配属错位。
写成「天＝自性本体」。原型明定：色属地（承载）、受想行属人（感应、裁断、迁化）、识属天（神明、了别）。自性不在三才任何一位，它是统摄三才的太极。此位一错，就会顺手把自性塞进杯里当成一层东西。

误二：把「空」降成杯内腔。
写成「杯里能盛」「杯子装水」。原型图上「空」字虽写在杯内，义上明写：「空相不是杯子里面狭小的中空，而是超越五蕴器相边界的全体实相」「不是杯子内部的空间容纳宇宙，而是空性可以超越杯子这个有形之器」。空若被塞回杯壁以内，芥子纳须弥就讲反了。

误三：漏掉阴阳与太和。
风幡公案本是阴阳对待之局：幡为阴（有形可睹），风为阳（无形而有动能）。二僧各执一端，是把一体的太和拆成两半。慧能所指之心，不是阴阳中任一边，是涵摄阴阳的太和。这一层不讲，「仁者心动」只能讲成「别争论」，落不到般若上。

三、本版所用原型（照录《心经通释》原版）

四、本版义理骨架

四根柱子，撑起全篇：

  1. 体：五句所证，是那个不被五蕴器框拘限的空性本际。
  2. 用：风幡落在五蕴缘起里，如实显现，不废。
  3. 阴阳：幡阴风阳，二僧各执一边，太和被拆成两半。
  4. 心：慧能所指之心，是涵摄阴阳的太和，是指代词——此心非心，故名此心。不住五蕴，亦不住空。

正文

弁言

慧能闻「应无所住而生其心」而悟，流出自性五句；风幡公案，是这一句的现场勘验。

幡是阴，有形可见；风是阳，无形而能起吹动之能。二僧各抓一端，落在阴阳分判的两边。慧能点出的「心动」，不在阴阳任一边，是阴阳未分而同时涵摄阴阳的太和本心。

这个「心」是指代词，正对《金刚经》「应无所住而生其心」：不住五蕴，亦不住空。此心非心，故名此心。

五句明体，风幡显用；体用同证，以太和统摄阴阳二相。

一、逐句通释：五句与空杯

何期自性，本自清净；
何期自性，本不生灭；
何期自性，本自具足；
何期自性，本无动摇；
何期自性，能生万法。

1. 本自清净

清净不是说器相之上没有尘垢。

尘垢、烦恼、苦受，都是附着在杯底、杯壁（色受想行识）之上的缘起痕迹。五蕴这个器可以沾痕，但承载整套器相的空性本际，从来不受沾染。

垢是缘生之相，不是空性本身。如同杯壁蒙尘，虚空不因壁上之尘而污浊。清净是空性本际的特质，不是把五蕴擦到一尘不染才叫清净——那样修，修的是杯壁，不是见地。

2. 本不生灭

生灭只属于杯这个器相。因缘会聚，色受想行识配合，杯相显现；因缘消散，底与壁的和合解体，杯相随之消散。

但托举这一套器相显现的空性，不因杯相成型而新生，不因杯相消散而毁灭。

有生有灭的是五蕴和合之器；不生不灭的是超越器相边界的实相。原型那句注最好用：杯体不因聚而生，不因散而灭其相用。

3. 本自具足（全篇核心，最易误读）

具足，不是空性里面预先存放了一切事物、答案、功德；也不是器本身自带什么储备。

具足说的是：空性本际不受五蕴器相的边界限制。因缘一熟，色受想行识便可构器、便可显相。它天然具备「容许一切缘起显现」的全体可能，无欠、无局。

杯子的器相有大小、有疆界；空性无界——芥子可以纳须弥。不是小杯装下大山，是器的边界本非实有，空性本际不受这层框限。

勘定：具足 ≠ 现成拥有。具足是「具备显现一切的可能」，不是「里面已经装好万物」。

4. 本无动摇

动摇、动荡、起伏，发生在五蕴器相之中。受有苦乐起伏，想有取舍分别，行有趋避迁转，识有了别归档不休。器内念念流转，一刻不停。

但空性本际不随五蕴流转而摇。器中波澜万千，承载波澜的实相如如安住。

不是熄灭念头、止住感受才叫不动；是知道所有动荡都在缘起器相之内，不把器的动荡当成自己的动荡。

5. 能生万法

正因自性是空、不受器框局限，因缘一聚，色受想行识和合，便构筑种种器相，显现万法。

万法全部依托五蕴这套缘起框架而现。空不是死寂的空无，是空而能显：缘起则万象现。

空性不主动造作万法，只是万法显现的依托——如虚空不主动生出山河，山河依托虚空才得显现。

二、风动、幡动、仁者心动：阴阳、太和与此心非心

时有风吹幡动。一僧曰风动，一僧曰幡动。议论不已。慧能进曰：不是风动，不是幡动，仁者心动。

1. 幡为阴：有形之相，落在杯底「色」

幡肉眼可睹，有形、有边界，属阴。它是色法显现，是五蕴器相的一环。僧人执幡，是把动因锁在有形这一侧。

2. 风为阳：无形之能，隐而推动色相

风看不见，无固定形质，却有吹动、变化的势能，属阳。另一位僧人执风，是把动因锁在无形那一侧。

这两个人，把本自一体的太和拆成阴阳两端，各守一边，互不相下。这就是「合」：以分别造作割裂整体，立起对立的疆界。

3. 太和，即慧能所说之心

风与幡是一对对待之相。阴阳相待，才有动静可辨。

而太和不是风，也不是幡；是能涵容阴阳、不落阴阳任一端的本心。这个心不追阴相，不逐阳能；它同时照见「有形的幡」与「无形的风」，知其本是一体流转。

4. 契《金刚经》：此心非心，故名此心

  • 不住阴：不黏在幡上，不黏在有形色相上，不在受想行识里争一个是非。
  • 不住阳：不黏在抽离出来的那股无形之风上，也不逃入一个孤悬的空境里。

不黏两边，而阴阳万象于中显现、于中流转。这颗太和之心，不是五蕴里的分别识，也不是一个可以捧住的实体——所以此心非心，故名此心。

「心动」之「动」，于是不是念头扰动，而是太和本心的照用：容阴阳、贯动静，不被两边的边界困住。

《金刚经》第十八分：过去心不可得，现在心不可得，未来心不可得。三心既不可得，则此心无自体；无自体而能照，故名此心。

5. 空杯视角收束

五蕴构出边界，我们才分出「可见的幡」与「不可见的风」；超越这套五蕴边界的空性本际，就是太和的基底。

阴阳是在空性之上显现的对待相；太和本心，是空性之起用——含摄阴阳，而不被阴阳分割。

通俗收束：执幡，执阴；执风，执阳。都落在对待两边。慧能的本心是太和：阴阳同存，一体无碍，不抓任何一边，无所住而生其照。

三、和合之辨总摄

  • 和：太和本心、空性自性，超越五蕴器相边界，涵摄阴阳，无对立，本自圆满。五句所证即此本际；「无所住而生其心」即此本际之起用。
  • 合：色受想行识因缘构器，划定疆界，割裂阴阳，立二元对立、起取舍攀缘。二僧辩论，正是「合」的造作；而枯守一个空境，也是另一种「合」——把空做成了可抓取之物。

修行落点，不是打碎五蕴、不要感知觉知；也不是死死抱住一个空境。照常启用色受想行识这套缘起之器，清清楚楚看见阴（幡）、阳（风）在流转，但不被阴阳的分别困住，安住太和。

五、收尾结义

自性五句，揭示太和空性本来圆满；
风幡公案，勘破阴阳对待的迷局。

幡是阴，形显；风是阳，能隐。世人惯在两端取舍争执。
慧能点出的本心，是统摄阴阳的太和。

不落阴阳二边，应无所住而生其心——正是《金刚经》一脉的般若。

附记

一、本篇模型用语，一律照《心经通释》原版：杯底色，四壁受想行识，空为超越器相边界之全体实相。不新造名相，不用「杯中盛物」一类说法。

二、《坛经》宗宝本，风幡一段记于《行由品》末（印宗法师讲《涅槃经》于法性寺时）；五句记于同品五祖夜授《金刚经》处。

三、本篇所论太和，取《易传》「保合太和」之义，与本书「和 / 合之辨」相接：和是本具，合是拼凑；太和不是阴阳之上的第三样东西，是阴阳本不曾分的那个状态。
